# Presentation materials

| file | what it is | when to use |
|---|---|---|
| **`SLIDES_TEXT.md`** | **paste-ready slide text** — title + bullets for 6 slides | building the actual PPT/Google Slides deck |
| **`PRESENTATION_SHORT.md`** | **6-slide plan + detailed speaker notes** (90 s–2.5 min scripts) | rehearsing the talk |
| `HANDOUT.md` | one-page printable summary | handing to the professor |
| `PRESENTATION.md` | full 22-slide deck + 4 backup slides (with visuals & notes) | if more depth is needed |
| `SPEAKER_NOTES.md` | 30 s script for each of the 22 slides + 8-question Q&A bank | extra Q&A practice |

**Suggested flow:** `SLIDES_TEXT.md` → build the deck → rehearse with `PRESENTATION_SHORT.md` → print `HANDOUT.md` → keep `PRESENTATION.md`/`SPEAKER_NOTES.md` as backup.

All numbers in these files are verified against the reports in `../outputs/`.
